# PYTHON PROGRAMMING – CASE STUDY SOLUTIONS (11–20)

## Project Overview
This project contains 10 individual Python case studies developed using the concepts covered in the prescribed Python programming syllabus.

The main objective is to apply computational thinking, problem-solving techniques, algorithms, pseudocode, flowcharts, and Python programming concepts to solve real-world problems.

## Case Studies Included

1. **Examination Result and Grace-Mark Validation** – Processes subject marks, applies grace marks, and generates final classifications.
2. **Attendance Recovery Computation** – Calculates attendance percentages and minimum classes required to reach eligibility.
3. **ATM Transaction Sequence Simulation** – Simulates deposits and withdrawals, validates transactions, and maintains account balance.
4. **Warehouse Inventory Reconciliation** – Compares stock quantities, identifies discrepancies, and calculates replenishment requirements.
5. **Smart Parking Fee Management** – Calculates parking charges based on vehicle type, duration, overnight parking, and penalties.
6. **Multi-Day Water Tank Simulation** – Simulates water inflow and outflow, detects overflow and shortages, and checks water-level thresholds.
7. **Student Performance Trend Analysis** – Compares examination scores, identifies improvements and declines, and classifies students.
8. **Fuel Consumption and Route Comparison** – Calculates fuel requirements and journey costs to identify the most economical feasible vehicle.
9. **Multi-Product Shopping Budget Constraint** – Calculates shopping costs, applies discounts, and adjusts quantities to meet a fixed budget.
10. **University Admission Decision Engine** – Evaluates candidates, checks eligibility, and generates ranked admission lists.
